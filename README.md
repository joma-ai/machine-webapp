# Machine Management Web App (showcase)

This repository describes a full-stack web application I built for managing machines and their accounting data, also giving a simpler more understandable overview of the machines and their related info. The actual application code is private due to client use, so this repo contains an overview, screenshots, and example snippets.

## Features:
- User and group segregated DB
- JWT-secured login with cookie-based authentication
- Excel export for accounting data to be processed onwards
- Drag-and-drop ordering per user for specific objects
- Role and permission management by user and group
- Deployed full-stack setup using Docker on Render for the backend and a static frontend deployment

## Technologies used:
- **Backend:** Java, Spring Boot (JPA, MVC, Security), PostGreSQL(previously MySQL)
- **Frontend:** React (Vite, Router, dnd-kit, Axios)
